When the user asks for a review/analysis/strategy ("scan X and tell me what we can use"), the
deliverable is the written review. Don't gate it behind a round of clarifying questions.

**Why:** 2026-09-16 — after a full scan I opened with three AskUserQuestion items; the user said
"dont ask me things please write me review". Questions cost them a turn on a limited plan and
delay the thing they asked for.

**How to apply:** make the routine calls yourself, state each assumption in one line inside the
review ("Assumption: X — flip if Y"), and proceed. Ask only when a fact would make the whole
deliverable useless if wrong. [[feedback-ask-dont-assume]] still governs *diagnostic* facts
(symptoms, what was tried); [[feedback-discuss-before-building]] still governs *building* —
the review itself is the discussion.
